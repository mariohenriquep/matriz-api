# Matriz 0.7.1 — notas da versão

> **Estado: 0.7.1, 2026-11-16.** Fica marcada com a tag anotada `v0.7.1`, sem release no GitHub. Não é uma release de produção.

## Resumo

A 0.7.1 prepara a Matriz para ser publicada no plano gratuito do Render. A aplicação não muda para quem a usa.

## Novidades

- **Blueprint `render.yaml`**: cria no Render uma base de dados PostgreSQL 16 gratuita, o backend a partir da imagem `marrike/matriz-backend:0.7.1` do Docker Hub e o frontend como site estático. Guia passo a passo e limites do plano gratuito em [`docs/deploy-render.md`](../deploy-render.md).
- O backend aceita o endereço da base de dados em partes (`MATRIZ_DB_HOST`, `MATRIZ_DB_PORTA`, `POSTGRES_DB`), porque o Render não dá um endereço JDBC.

## Alterações que pedem atenção ao atualizar

Nenhuma. `MATRIZ_DB_URL` continua a ter prioridade; não há migrações nem dependências novas.
