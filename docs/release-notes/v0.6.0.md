# Matriz 0.6.0 — notas da versão

> **Estado: 0.6.0, 2026-11-16.** Extras do MVP depois das fichas. Fica marcada com a tag anotada `v0.6.0`, sem release no GitHub. Não é uma release de produção.

## Resumo

A 0.6.0 traz o quadro Kanban, o arquivo de projetos e um visual novo, desenhado primeiro no Figma.

## Novidades

- **Quadro Kanban** (RF-15, US-13): na página de cada projeto, as tarefas aparecem em três colunas (Por fazer, Em curso, Concluída). Arrastar um cartão para outra coluna muda o estado. Para teclado e ecrãs táteis, cada cartão tem um seletor "Mover para". A lista anterior continua em "Lista".
- **Arquivo de projetos** (RF-18, US-16): o Gestor arquiva e reativa o projeto. Um projeto arquivado sai da lista principal, aparece em "Arquivados" e fica só de leitura. Continua a poder ser eliminado.
- **Novo visual:** barra lateral, cartões de resumo por estado, cartões de projeto e de tarefa com cores por estado e prioridade, modo escuro e versão para telemóvel. O tipo de letra (Inter) é servido pela própria aplicação.

## API

- `POST /projetos/{id}/arquivar` e `POST /projetos/{id}/reativar` (só o Gestor).
- `GET /projetos?arquivados=true`; sem o parâmetro, só os projetos ativos.
- Campos `arquivado` e `arquivadoEm` no `Projeto`.
- Alterar um projeto arquivado (ou as suas tarefas, membros, responsáveis e comentários) dá `409` com o tipo `/erros/projeto-arquivado`.
