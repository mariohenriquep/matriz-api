# Matriz 0.7.0 — notas da versão

> **Estado: 0.7.0, 2026-11-16.** Fica marcada com a tag anotada `v0.7.0`, sem release no GitHub. Não é uma release de produção.

## Resumo

A 0.7.0 traz um quadro geral na página inicial: as tarefas de todos os projetos ativos num só Kanban, sem ser preciso abrir cada projeto.

## Novidades

- **Quadro geral** (separador "Quadro geral" na página inicial e na barra lateral): três colunas (Por fazer, Em curso, Concluída) com as tarefas de todos os projetos ativos de que o utilizador é membro. Cada cartão mostra o nome do projeto, com ligação para ele.
- Arrastar um cartão, ou usar "Mover para", muda o estado como no quadro de cada projeto. O resumo do painel atualiza-se logo.
- **Filtros** por projeto, por prioridade e "Só as minhas" (tarefas de que o utilizador é responsável, em todos os projetos; RF-17).
- Os projetos arquivados ficam de fora, porque são só de leitura.

## API

- `GET /tarefas?projetoId=&estado=&prioridade=&responsavelId=`: novo, todos os parâmetros opcionais. Um `projetoId` arquivado ou de um projeto de que o utilizador não é membro devolve uma lista vazia.

## Alterações que pedem atenção ao atualizar

Nenhuma. Não há migrações nem dependências novas; os endpoints existentes não mudam.
